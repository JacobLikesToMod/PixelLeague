# PixelLeague
Open source blocky Rocket League styled HTML game.

## How 2 Play 
Head over to [Pixel League](https://google.com) and start playing!

Just imagine Rocket League, **but blocky.**

## Modes
There are 5 Modes.
• Freeplay
• Bot Mode
• Online (need server)
• Ranked 2v2’s
• Casuals (with bots)

## Cars
There are 3 Cars
***Dominus*** - Pixelinus
***Fennec*** - Pixelennec
***Octane*** - Pixeltane
